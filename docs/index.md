# pygeofilter-aeronet

Use CQL2 JSON filters to query AERONET observations, discover stations, and save results as CSV and GeoParquet with STAC metadata.

The documentation follows [Diátaxis](https://diataxis.fr/). Choose a section according to what you need:

| Your goal | Start here |
| --- | --- |
| Learn by completing a first query | [Tutorials](tutorials/index.md) |
| Complete a specific task | [How-to guides](how-to/index.md) |
| Look up commands, filters, or Python functions | [Reference](reference/index.md) |
| Understand how the client works | [Explanation](explanation/index.md) |

New users should start with [Your first AERONET query](tutorials/first-query.md).
