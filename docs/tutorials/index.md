# Tutorials

Follow a guided exercise to learn the client, then explore the notebooks.

1. [Your first AERONET query](first-query.md): install the package, build a filter, preview the request, and read observations.
2. [Translate a filter into API parameters](filter-translation.ipynb): inspect the query string in a notebook.
3. [Retrieve and map Level 1.0 AOD](../samples/level_10.ipynb): display observations in a table and on a map.

For notebooks, install `jupyterlab` and `folium` alongside `pygeofilter-aeronet`, open the notebook in JupyterLab, and run cells in order. They use live services; results can change. Downloads are written to the notebook's working directory.
